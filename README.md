# Critter Tank Battle (坦克大战)

A tribute to the 1985 NES / Subor (小霸王) *Battle City*, starring **Mikey & JJ** and the **Smiling Critters**.
It's plain HTML, CSS and JS with no build step: open `index.html` or visit the GitHub Pages site.

**Play:** https://kunruiw1991.github.io/critters-tank-battle/

## Cast
| Role | Character |
|---|---|
| Player 1 tank | Mikey (green turtle hood) |
| Player 2 tank | JJ (blue hoodie) |
| Basic villain | Huggy Wuggy |
| Fast villain | Mommy Long Legs |
| Power villain (fast shots) | Bunzo Bunny |
| Armor villain (3–4 hits) | PJ Pug-a-Pillar |
| Base to protect | Critter Home 🏠 |

Villains that pulse red drop a Smiling Critters friend when hit:

| Friend | Power |
|---|---|
| DogDay | Super shots (star, up to 3 levels; level 3 breaks steel) |
| Bobby BearHug | Big hug shield |
| Hoppy | Freeze all villains |
| CraftyCorn | Rainbow steel wall around Critter Home |
| KickinChicken | Confetti pop: clears the villains on screen |
| Bubba | Extra tank |
| SunnyFox (Mom) / PoppyDash (Dad) | Helper tank fights with you for 20 s |

## Controls
- **Mikey:** WASD to move, Space to fire. **JJ:** arrow keys to move, Enter to fire. In 1-player mode the arrow keys also drive Mikey.
- **Pause / resume:** P or Esc. The top bar has Start, Pause, Stop, Music and Sound buttons.
- **iPad:** an on-screen joystick and FIRE button appear automatically.

## Speed
- 🐌 **Super Gentle** (default): slow villains, 4 lives, and Critter Home takes 3 hits.
- 🐢 **Gentle**
- 🐇 **Classic**: close to the original NES pace.

## Modes
- 1 player
- 2 players on the same keyboard
- **Construction:** paint your own map, then play it. The map is saved in the browser.

The game has 6 stages. The music is original NES-style chiptune made with WebAudio.
